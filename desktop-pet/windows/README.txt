AlreaDough 桌宠（Windows 版）

怎么打开
1. 把整个「AlreaDough Pet」文件夹解压出来，放在哪里都可以（比如「文档」或「桌面」）。
2. 双击「AlreaDough Pet.exe」，面团会出现在屏幕右下角。
3. 如果出现「Windows 已保护你的电脑」：点「更多信息」，再点「仍要运行」。

怎么玩
- 轻点面团会弹一下；连点三下开一场醒发派对。
- 拉一拉会拉长；拉得够远它会挣脱，跟着你走，放在屏幕任何地方都行。
- 按住不动 0.4 秒再拖，也能把它拿起来。
- 在面团上滚动鼠标滚轮，它会变大变小再弹回来。
- 双击面团会打开 AlreaDough。
- 右键面团（或者右键时间旁边的小面团图标）：换大小、躲一会儿、开机时自动出现、放回右下角、退出。
- 全屏看视频、玩游戏、放幻灯片时，它会自己躲开，结束后再回来。

想让它下班：右键 → 退出桌宠。想彻底删除：退出后直接删掉这个文件夹。

AlreaDough Pet (Windows)

Getting started
1. Unzip the whole "AlreaDough Pet" folder anywhere you like.
2. Double-click "AlreaDough Pet.exe". The dough appears in the bottom-right corner.
3. If Windows says it protected your PC: click "More info", then "Run anyway".

Playing with it
- Tap the dough to make it bounce; three quick taps start a proofing party.
- Pull it and it stretches; pull far enough and it breaks free and follows you anywhere on screen.
- Or hold it still for a moment, then drag to pick it up.
- Scroll the mouse wheel over it to make it grow or shrink; it springs back.
- Double-click it to open AlreaDough.
- Right-click it (or the little dough icon by the clock) to resize it, hide it for a while, start it with Windows,
  send it back to the corner, or quit.
- It steps aside by itself while a film, game or slideshow is full screen.

To remove it: right-click → Quit, then delete this folder.
